INSTRUCTIVO PARA LA REMISIÓN DE UN EXPEDIENTE 
A LISTA DIARIA CON MOVIMIENTO POSTERIOR 
 
 
1- Para remitir un expediente a Lista Diaria se debe seleccionar la función MOVIMIENTO, y 
luego NUEVO MOVIMIENTO. 
 
 
 
2- En el Tipo de Movimiento seleccionar “Lista- Lista Diaria” 
 
 
 
3- Se abrirá automáticamente un cuadro que indica las actuaciones disponibles para 
publicar en lista, debiendo tildar las que se desean publicar para que sean incluidas. 
Una vez elegidas y tildadas, confirmar.

5- Seleccionar Motivo/Ubicación: EN LISTA DIARIA, es la única opción que da. 2° 
6- Finalmente, hacer clic en ENVIAR. 3° 
 
 
 
7- Una vez cargado en lista, se debe seleccionar otra vez la función NUEVO MOVIMIENTO, 
para registrar el movimiento siguiente que corresponde.
